# IPv6 connection policy

Add a persisted, global IPv6 switch to ProxyListActivity, enabled by default.
When disabled, tgnet, SOCKS5/MTProto proxy connections, native VoIP and both
tunnel protocols must use IPv4 only. IPv6 literals and IPv6-only DNS answers
fail closed; mixed DNS answers retain IPv4. WEB proxy is explicitly exempt.
Saved profiles remain intact, including their IPv6 configuration.

Use a shared native address policy at socket creation and tgnet strategy
selection, plus an equivalent policy in the Go tunnel runtime. Merely setting
tgnet's initial IPv4 strategy is insufficient because retries can change it.

Do not interrupt calls. While any private, group, conference, screencast or live
native VoIP instance exists, defer applying the global setting (including the
tunnel restart) until the final instance stops. Explain this in the settings UI.
This avoids changing the outer tunnel underneath an active call. Apply the
persisted preference before networking at the next process startup.

No device VPN, route fallback, profile rewriting or secret logging. Verify using
the canonical tunnelPackageDebug command and update tunnel documentation.
