# IPv6 Implementation Plan

**Goal:** Add a global IPv6 setting, except for WEB proxy, without interrupting calls.
**Architecture:** Persist desired policy in Java; defer effective changes while native
VoIP sessions exist. Enforce effective policy in tgnet/WebRTC and Go. Restart
tunnel and ordinary Telegram transports only when safe.
**Spec:** docs/superpowers/specs/2026-11-14-ipv6-design.md

## Constraints and review focus

Keep tunnel routes fail closed, profiles encrypted and unchanged, and tgcalls
upstream untouched. Test IPv6 literals, IPv4-mapped literals, IPv6-first DNS,
IPv6-only profiles/DNS, retry strategy widening, overlapping calls, and toggling
back before calls end. WEB proxy stays exempt.
